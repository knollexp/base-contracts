# base-contracts

[![CI](https://github.com/knollexp/base-contracts/actions/workflows/ci.yml/badge.svg)](https://github.com/knollexp/base-contracts/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Base](https://img.shields.io/badge/deployed-Base%20mainnet-0052FF)](docs/addresses.md)

Eleven small, self-contained Solidity contracts and a minimal deploy script for
Base. No framework, no imports, no proxies, no funds held: every contract is
non-payable and has an argument-less constructor.

All eleven are [live on Base mainnet](docs/addresses.md).

## Contracts

| Contract        | Purpose                                            |
| --------------- | -------------------------------------------------- |
| `Greeter`       | Stores a greeting string, emits on change          |
| `Counter`       | Increment / decrement with underflow guard         |
| `KeyValueStore` | Per-address `bytes32 -> string` storage            |
| `Guestbook`     | Append-only signed messages, 280 byte limit        |
| `NameRegistry`  | One-name-per-address claim and release             |
| `TodoList`      | Per-address task list with one-way completion      |
| `Poll`          | One-vote-per-address yes/no poll                   |
| `Whitelist`     | Owner-managed allowlist with ownership transfer    |
| `VersionLog`    | Monotonically increasing semver release log        |
| `Attestation`   | Timestamped digest attestations, duplicate-guarded |
| `BuilderBadge`  | One-time non-transferable claim record             |

Each contract carries NatSpec explaining its tradeoffs. [SECURITY.md](SECURITY.md)
collects the known limitations in one place. Nothing here is audited.

## Layout

```
contracts/      Solidity sources
abi/            Exported ABIs, regenerated by npm run abi
test/           Test suite plus the in-process EVM harness
scripts/        ABI export, gas report, Basescan verification
docs/           Deployed addresses and the gas report
compile.js      solc wrapper with an EIP-170 size guard
deploy.js       Deployment, dry run by default
```

## Setup

```
npm install
npm run compile
```

## Tests

```
npm test
```

The suite runs against an in-process EVM ([@ethereumjs/vm](https://github.com/ethereumjs/ethereumjs-monorepo)),
so there is no anvil or hardhat node to start. `test/harness.js` handles
deployment, ABI encoding, event decoding and revert-reason extraction; the
individual suites contain no ABI plumbing. The harness has its own tests,
because everything else trusts it.

## Deploy

The script is a dry run unless you pass `--yes`. It prints the deployer,
balance, per-contract gas estimates and total cost first.

Put your key in `.env` (gitignored, see [.env.example](.env.example)):

```
PRIVATE_KEY=0x...
```

Then:

```
node deploy.js --network base           # dry run, sends nothing
node deploy.js --network sepolia --yes  # rehearse on testnet
node deploy.js --network base --yes     # broadcast
```

Addresses and transaction hashes land in `deployments.<network>.json`, which is
gitignored.

The deployer of a contract is the address that sends the creation transaction,
so deploy from the address you want credited. The printed cost estimate covers
L2 execution gas only; Base additionally charges an L1 data fee per
transaction, so the real total runs somewhat higher.

## Other scripts

| Command           | What it does                                            |
| ----------------- | ------------------------------------------------------- |
| `npm run compile` | Compiles and reports sizes against the EIP-170 limit    |
| `npm run abi`     | Regenerates `abi/`, removing stale files                |
| `npm run gas`     | Regenerates [docs/gas.md](docs/gas.md) from the harness |
| `npm run verify`  | Submits sources to Basescan (needs `BASESCAN_API_KEY`)  |
| `npm run format`  | Applies prettier                                        |
